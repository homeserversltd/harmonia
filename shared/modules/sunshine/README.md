# Shared owner desktop streaming

HomeConsole selects this shared job. Its pool renders the original `gamepad = ds5` configuration byte-for-byte and selects no owner-unit or service action; the console's null service values are a no-op even if an operator has a local Sunshine unit. Birth supplies the binaries.

HomeSI instead selects the distinct profile-local `sunshine-homesi` job. It keeps wlroots capture, disabled UPnP and a LAN-origin Web UI and maintains the `sunshine@.service` template without starting or enabling it. Caduceus PID 2 selects the owner's screen or headless seat; the Sway session handoff brings up the session services. Hermes's private seat is separate. The household owns its router; this configuration makes no claim about a household-created port forward.
