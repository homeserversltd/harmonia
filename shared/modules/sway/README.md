# sway

The shared owner desktop job for HomeTV and HomeSI. The selected profile pool supplies output and shortcut fragments; the common payload supplies Sway defaults, window rules, Wofi and session handoff units. The thirteen managed files are declared in `manifest.json`. `input.conf` includes the unmanaged operator/Caduceus `input-overrides.conf` after the defaults so local overrides retain precedence; this module never creates that seed. Configuration differences remain per-item interactables.

HomeTV uses Mod4 for Super and Mod1 for Alt. Super+K opens the calculator. Native `app_id` and Xwayland `class` selectors cover the matching window types, with separate title selectors where needed. `floating_modifier Mod4 normal` carries Super+left move and Super+right resize. Super+Shift+left bridges to Sway's native right-button resize gesture through `seat - cursor press button3` and `seat - cursor release button3`; Shift retains the aspect-ratio constraint. Sway documents that cursor-command path as deprecated in favor of the virtual-pointer protocol. Config validation alone does not prove the runtime gesture. The face owns the three-workspace navigation ring and carry behavior.

The direct Sway `exec` invokes `/usr/bin/flock --exclusive` on `$XDG_RUNTIME_DIR/hometv-sway-handoff.lock` around `/usr/bin/systemd-run --user --wait --collect --service-type=oneshot`. Its transient bootstrap probes the captured `${SWAYSOCK}` with `/usr/bin/swaymsg --quiet --socket=${SWAYSOCK} --type=get_version` before stopping a target or changing the activation environment. An old/dead queued callback skips without replacing a newer session's environment. The bootstrap stops `hometv-sway-session.target` and `graphical-session.target`, imports the descendant's `WAYLAND_DISPLAY` and `SWAYSOCK` through `/usr/bin/dbus-update-activation-environment --systemd`, then synchronously starts `hometv-sway-session.target`. The flock lease covers completion of that target request.

The managed `hometv-sway-environment.service` is `Type=oneshot` without `RemainAfterExit`. It declares the static session environment, with `XDG_SESSION_DESKTOP` and `XDG_CURRENT_DESKTOP` set to `sway`. Dynamic `WAYLAND_DISPLAY` and `SWAYSOCK` come from the serialized bootstrap. Its native `ExecStartPre` conditions require both values and live Sway IPC; two serial `ExecStart` commands import the full environment into D-Bus activation and the user manager. The unit precedes both session targets and the Waybar/Dunst units. Both target declarations require and order the importer so an importer failure cannot start the graphical wants. No package installation, display-manager configuration, or live-session operation belongs to this module.
