# service-runtime

`service-runtime` is a registered Harmonia tool declaration resolved through `src/tools/index.json`, the single registry. `service-runtime` is a registry entry in `src/tools/index.json` with permutation `converge`; it is lowered to primitive declarations before execution and is not one of the thirteen deed declaration records. The thirteen records carry the deed/permission/phase truth; this registry entry does not add a separate deed authority.

The two required mutation keys are diff-minted `Authorization` and the exact `--apply-or-timer` invocation key.
