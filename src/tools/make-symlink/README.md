# make-symlink

`make-symlink` is a registered Harmonia tool declaration resolved through `src/tools/index.json`, the single registry. `make-symlink` is one of the thirteen deed declaration records in `src/tools/index.json`: permutation `link`, deed `make-link`, permission `mutate`, and phases `observe → compare → act → attest`. It makes a declared link through the keyed transactional do atom.

The two required mutation keys are diff-minted `Authorization` and the exact `--apply-or-timer` invocation key.
