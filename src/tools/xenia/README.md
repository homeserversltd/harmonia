# Xenia tool

`xenia/converge` and `xenia/retire` are declaration-only. The lowering owner reads the public `appliance.xenia.v1` seat and guest register before ordinary service-runtime and managed-file lowering.

Unit rendering is authorized only by the guest-register law and the selected entry's `install.unit` declaration. The renderer constructs the unit from typed entry fields and the current Caduceus bind declaration; this tool seat contains no literal unit template.
