# enable-unit

`enable-unit` is a registered Harmonia tool declaration resolved through `src/tools/index.json`, the single registry. `enable-unit` is one of the thirteen deed declaration records in `src/tools/index.json`: permutation `enable`, deed `change-unit`, permission `mutate`, and phases `observe → compare → act → attest`. It enables a declared unit through the keyed transactional do atom.

The two required mutation keys are diff-minted `Authorization` and the exact `--apply-or-timer` invocation key.
