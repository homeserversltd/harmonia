# Atoms

Atoms host Harmonia's primitive operations and engines. The atom floor includes comparison, command capture, AUR, Git artifact, systemd, package, declaration, and `declarations.json` handling, together with the `ask`, `do`, and `attest` surfaces.

`ask` observes, `compare` derives typed drift, `do` performs an admitted deed, and `attest` redacts and forwards the receipt. The twenty true-named transactional atoms under `src/atoms/do/` are the only mutation vocabulary. Each mutating atom requires diff-minted `Authorization` and the exact `--apply-or-timer` invocation key.
