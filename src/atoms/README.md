# Atoms

The engine floor is a breath-shaped `ask -> do -> attest` path. `ask` observes typed drift without blocking; `do` is admitted only with a by-value authorization minted by the comparison gate; `attest` appends one redacted receipt to the appliance stream and forwards it to Hyalos.

The two keys are **observation** and **authorization**. Profile locks, tests, reserve, monad, and migration remain explicit profile surfaces; this landed slice establishes only the atoms floor.
