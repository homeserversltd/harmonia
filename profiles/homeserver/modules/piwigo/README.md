# Piwigo

This module carries the HOMESERVER product Piwigo desired state lifted from the private initialization quarry. Harmonia maintains PHP-FPM configuration and service flags on an already-born appliance; it does not install PHP, Piwigo, MariaDB, or nginx, create accounts or databases, download application releases, initialize the gallery, or own gallery data.

The ladder:

- fails closed unless the birth-provided PHP-FPM runtime and Piwigo application exist;
- requires the NAS photo directory and installed `database.inc.php` to exist but never writes either one;
- converges the quarry PHP-FPM pool, generated distro-extension marker, and shared flat-path PHP-FPM unit with backups of replaced files;
- enables the marker through a PHP-FPM-validated link;
- validates the complete PHP-FPM configuration and installed unit;
- reloads systemd and restarts PHP-FPM only when this module changed managed material;
- enables PHP-FPM when needed and proves it is active.

`piwigo.conf` preserves the quarry text with only a final newline added for repository-safe module form; `php-fpm.service` is byte-exact. The carried `piwigo.ini` externalizes the exact static line generated by the quarry installer so Harmonia can converge it without executable manifest text. `database.inc.php` is a user-editable birth seed: the quarry example password is replaced by the unfilled `${PIWIGO_DB_PASSWORD}` placeholder, trailing space is removed, and a final newline is added; the appliance copy is only checked for non-empty presence, never overwritten.

The quarry `install.py` is birth machinery and is not carried. `installerWindow.md` is operator guidance rather than installed desired state. The unused `piwigo.service` contradicts the living installer, which installs and runs the shared `php-fpm.service`, so it is not treated as active product configuration.

Piwigo uploads and local configuration under `/opt/piwigo/piwigo`, gallery content under `/mnt/nas/photos`, MariaDB data and credentials, PHP-FPM logs and runtime state, and the downloaded Piwigo application are instance or birth material and are not carried. The module crosses into the NAS photo directory, MariaDB, nginx's `photos.home.arpa` virtual host, and the birth-provided flat PHP-FPM substrate without absorbing those concerns' configuration.
