# Harmonia self-maintenance

Harmonia keeps its engine current through the same one-breath ritual as every maintained concern: `ask → compare → do → attest`.

The module composes the declared source, build, binary, service, and health work through the single registry at `src/tools/index.json`. Mutating work follows the current band → owning tool → atom path; `renew-self` uses its `replace_process` path as the self-maintenance exception. The module reports its result with the run's closing census.

The installer remains the owner of installation layout and scheduled service material. This module does not add a second mutation vocabulary or schedule.
