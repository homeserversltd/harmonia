# Harmonia self-maintenance

Harmonia keeps its engine current through the same one-breath ritual as every maintained concern: `ask → compare → do → attest`.

The module composes the declared source, build, binary, service, and health work through the single registry at `src/tools/index.json`. Any mutating step resolves to a keyed transactional do atom; the two keys are diff-minted `Authorization` and `--apply-or-timer`. The module reports its result with the run's closing census.

The installer remains the owner of installation layout and scheduled service material. This module does not add a second mutation vocabulary or schedule.
