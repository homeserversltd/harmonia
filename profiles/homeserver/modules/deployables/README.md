# Deployables freshness

The gateway packs Midas births from its own `deployables` checkout.

For one arm, request fresh source packing with:

```text
cli.py deploy midas-touch <target> --fresh
```

`--fresh` mints a fresh intent id, forcing that arm to pack fresh source. It is the per-arm source-freshness lane; it is not convergence machinery.

Continuous checkout currency belongs to Make Modern possession on the gateway body. This documentation entry creates no deployables convergence steps, package steps, timers, or update service.
