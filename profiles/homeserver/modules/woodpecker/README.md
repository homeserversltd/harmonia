# Woodpecker

This module carries configuration for the household's Woodpecker server and local agent. Birth provides both executables, the `woodpecker` and `woodpecker-agent` users and groups, writable `/var/lib/woodpecker` and `/var/lib/woodpecker-agent` directories owned by their respective users, enabled units, and both instance environments. Birth places `/etc/default/woodpecker-server` and `/etc/default/woodpecker-agent` as `root:root` `0600`; systemd reads each before dropping privileges. Harmonia requires both files, maintains their root-only metadata and the two unit files, and never overwrites the instance environments or installs binaries.

The server environment seed contains `${WOODPECKER_AGENT_SECRET}`, `${WOODPECKER_FORGEJO_CLIENT}` and `${WOODPECKER_FORGEJO_SECRET}`. The agent environment seed contains `${WOODPECKER_AGENT_SECRET}` only. Birth fills the same agent secret in both files offline; its first-boot setup fills the server's Forgejo OAuth application values. The callback is `https://ci.home.arpa/authorize`. The server runs as `woodpecker`, uses `/opt/woodpecker/woodpecker-server` and `/var/lib/woodpecker`, and binds HTTP and gRPC to loopback ports 8000 and 9000. The agent runs as `woodpecker-agent`, uses `/opt/woodpecker/woodpecker-agent`, and stores registration in `/var/lib/woodpecker-agent/agent.conf`; its HOME and working directory are `/var/lib/woodpecker-agent`. Nginx serves the HTTPS name and Unbound resolves it.

The local backend runs pipelines as `woodpecker-agent`, without isolation. They see the agent secret but not the server's Forgejo OAuth secret; the agent secret allows a process to join this household's Woodpecker as an agent, and is not a Forgejo OAuth credential. Only trusted repositories and workflows should be allowed. Forgejo's birth-owned app.ini permits private webhook targets; existing installations retain their instance config. Trust for the `git.home.arpa` certificate and an allowed Forgejo user remain integration prerequisites.

Upstream Woodpecker 3.18 configuration: https://woodpecker-ci.org/docs/3.18/administration/configuration/server (host, listeners, admin, registration and shared secret); https://woodpecker-ci.org/docs/3.18/administration/configuration/forges/forgejo (Forgejo URL, OAuth and callback); https://woodpecker-ci.org/docs/3.18/administration/configuration/agent (backend, gRPC address, agent secret and config file); https://woodpecker-ci.org/docs/3.18/administration/configuration/backends/local (local execution and trust boundary).
