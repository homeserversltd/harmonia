# desktop-config-payload

TV desktop files live inside this module under `files_root/<intent>/...`. The folder names are the thought/intent: `hyprland`, `kitty`, `wofi`, `gtk`, `kate`, `kde-applications`, `browser`, `launcher-bin`, `prompt`, `portal`, and `game-launcher`.

Do not create sibling `profiles/tv/config` payload folders. Profile files belong in the module that owns the intent.

`input-overrides.conf` is an empty source seed and operator override fragment, owned after birth by the Caduceus input-policy door. It is intentionally absent from `expected_files` and every Harmonia convergence files list. Harmonia must not create, replace, or overwrite it. The current TV deployable has no phase-6 pack/export carrier for this module payload, so birth delivery of the seed remains explicit deployables debt.
