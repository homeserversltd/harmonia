# desktop-config-payload

TV desktop files live inside this module under `files_root/<intent>/...`. The folder names are the thought/intent: `hyprland`, `kitty`, `waybar`, `dunst`, `gtk`, `kate`, `systemd-user`, `browser`, `shell-rc`, `prompt`, and `manifest`.

Do not create sibling `profiles/tv/config` payload folders. Profile files belong in the module that owns the intent.
